# MFFGCN 复现结果与论文对比分析

> 论文：*MFFGCN: Multimodal Feature Fusion Graph Convolution Network for Radio Map Estimation With Uneven Spatial Sampling*
> 数据集：RadioMapSeer（DPM 增益图，256×256，701 张地图 × 80 个发射机 = 56,080 样本）
> 环境：ZJUT 服务器 `192.168.66.148`，4×A100-PCIE-40GB，PyTorch 2.6.0 + CUDA 11.8

---

## 一、结论摘要

复现跑通了完整链路：数据获取、预处理、模型、损失、三种采样设置、50 epoch 训练、测试集评估、可视化。**但精度没有复现到论文水平，差距约一个数量级。**

| 采样设置 | 论文 NMSE | 我们 NMSE | 倍数 | 论文 RMSE | 我们 RMSE | 倍数 |
|---|---|---|---|---|---|---|
| Setup 1（全图均匀） | 0.0043 | **0.0770** | 17.9× | 0.0150 | **0.0728** | 4.9× |
| Setup 2（25% 受限区） | 0.0045 | **0.1016** | 22.6× | 0.0154 | **0.0836** | 5.4× |
| Setup 3（10–50% 可变受限） | 0.0046 | **0.1334** | 29.0× | 0.0155 | **0.0958** | 6.2× |

**最重要的一条证据**：同一个模型在**训练集**上的误差是 NMSE 0.0068 / RMSE 0.0136。也就是说，模型在被它见过的地图上，精度和论文报告的水平（0.0043 / 0.0150）几乎一致。差距 100% 出在**泛化**，不在模型实现、损失函数或数据管线。

这个结论有两层含义：

1. 我们的复现在"能力"层面是对的——结构、损失、训练配方都能把误差压到 0.007 级别；
2. 论文报告的测试误差**等于我们训练集上的误差**，意味着论文模型的训练/测试泛化差距接近于零。在一个"用未见过城市的地图做测试"的设定下，这个现象本身值得怀疑（见第五节）。

| 方法 | Setup 1（NMSE / RMSE） | Setup 2 | Setup 3 |

| AE（论文） | 0.0387 / 0.0456 | 0.0753 / 0.0627 | 0.0829 / 0.0657 |
| DeepAE（论文） | 0.0156 / 0.0288 | 0.0276 / 0.0319 | 0.0395 / 0.0422 |
| U-Net（论文） | 0.0063 / 0.0182 | 0.0075 / 0.0199 | 0.0081 / 0.0206 |
| RadioUNet（论文） | 0.0049 / 0.0160 | 0.0058 / 0.0175 | 0.0063 / 0.0181 |
| RME-GAN（论文） | 0.0043 / 0.0151 | 0.0051 / 0.0165 | 0.0055 / 0.0172 |
| MFFGCN（论文） | 0.0043 / 0.0150 | 0.0045 / 0.0154 | 0.0046 / 0.0155 |

趋势层面是对的：三个 Setup 的难度递增关系（S1 < S2 < S3）完整复现，这与"采样越不均匀越难"的物理解释一致。

## 四、差距分析：全部出在泛化

### 4.1 训练集与测试集的对照

| 评估对象 | NMSE | RMSE |
|---|---|---|
| 论文报告（测试集，未见地图） | 0.0043 | 0.0150 |
| **我们的模型 @ 测试集（未见地图）** | **0.0770** | **0.0728** |
| **我们的模型 @ 训练集（见过地图，800 样本）** | **0.0068** | **0.0136** |

泛化差距 = 0.0770 / 0.0068 ≈ **11.3 倍**。

我们的训练集 RMSE（0.0136）甚至**低于**论文报告的测试集 RMSE（0.0150）。也就是说，如果只看模型拟合能力，复现是达标的；差距完全来自"换一批没见过的地图就崩"。

### 4.2 误差的物理形态

抽查验证集样本（图见 `results/sample_s1_0.png` 等）：

- 预测与真值的空间相关系数 0.65–0.88，**亮区位置、阴影走向基本正确**；
- 误差集中在发射机附近的高值区，且预测系统性偏低；
- 线性幅度校准无效（最优缩放系数 0.98，NMSE 仅从 0.254 变到 0.254），说明不是简单的幅度偏移，而是高值区的细节被抹平。

这是 MSE 类损失在强稀疏、强动态范围问题上的典型表现：模型学会了"哪里会亮"，但不敢预测"有多亮"。

### 4.3 图卷积精化模块确实有效

| Setup | 粗估计 NMSE | 精化后 NMSE | 改善 |
|---|---|---|---|
| Setup 1 | 0.1146 | 0.0770 | **−32.8%** |
| Setup 2 | 0.1318 | 0.1016 | −22.9% |
| Setup 3 | 0.1240 | 0.1334 | +7.6%（反而变差） |

这与论文 Table V 中"去掉 GCN 会变差"的方向一致，说明动态图 + MRConv 的实现是起作用的。但在最难的 Setup 3 上精化阶段反而有害，提示 patch 级 KNN 图在观测极不均匀时构建出的邻接关系不可靠。

### 4.4 分区指标：模型是否真的用了观测值？

| Setup | 全图 RMSE | 受限区 RMSE | 观测像素 RMSE |
|---|---|---|---|
| Setup 1 | 0.0728 | — | **0.0018** |
| Setup 2 | 0.0836 | 0.0516 | **0.0025** |
| Setup 3 | 0.0958 | 0.0662 | **0.0028** |

观测像素上的误差比全图低 30–40 倍，说明**模型确实读了测量值并忠实重建了它们**；受限区误差低于全图，也与"有观测的地方更准"的预期一致。管线没有把观测信息丢掉。

### 4.5 不均匀采样的鲁棒性

| 指标 | 论文 | 我们 |
|---|---|---|
| Setup 1 → Setup 3 的 RMSE 增幅 | +3.3% | **+31.6%** |

论文声称对不均匀采样几乎免疫（+3.3%），我们的模型退化明显更严重。结合 4.1，这更像是同一个泛化问题的另一种表现：模型对训练时见过的采样模式过拟合，遇到受限区扩大就失稳。

## 五、两处需要指出的论文问题

### 5.1 Table I 与正文自相矛盾

Table I 给出的 U-Net 通道数是 6 / 40 / 50 / 60 / 100 / 100 / 150 / 300 / 500，卷积核在 3/4/5/13 之间跳变，下采样位置也不规则；但正文明确写"similar to [32]"（RadioUNet 的标准五级 U-Net）。

两者不可能同时成立。我们按正文声明 + RadioUNet 公共实现搭建，因此参数量（24.55 M）与论文模型不一定相同。这会影响绝对数值的可比性，但不解释 18 倍的差距——因为我们的训练集误差已经达到论文水平。

### 5.2 论文报告的泛化差距接近于零

这是更关键的一点。在"测试地图完全没参与训练"的设定下：

- 论文 MFFGCN：训练/测试差距 ≈ 0（报告值即测试值）
- 我们：训练 0.0068 → 测试 0.0770，差 11.3 倍

一个 24 M 参数的网络在 500 张地图、40,000 个样本上训练，泛化差距为零是反常的。可能的原因（按可能性排序）：

1. **划分方式不同**：若论文实际按"样本对"而非"整张地图"划分，测试地图在训练时见过（只是发射机位置不同），泛化差距自然接近零，0.0043 也完全可达；
2. 论文用了未在文中说明的强正则/早停；
3. 论文的观测点比"10–300 个随机像素"更密集，任务本身更容易。

我们为此专门跑了一组验证实验（按样本对划分，同一模型同一损失），结果见第六节——**它支持第 1 条**。

## 六、诊断实验：按样本对划分（已验证）

为了把"泛化"这个结论从推测变成证据，我们加跑一组对照：保持模型、损失、采样策略完全不变，只把划分方式从"按地图"改成"按样本对"（80/10/10 随机划分 56,080 个样本，测试地图在训练时出现过）。

- 训练集 44,864 / 验证 5,608 / 测试 5,608
- 10 epoch，第 8 epoch 衰减，其余超参与主实验一致

### 6.1 实验结果

| 配置 | 训练样本 | epoch | 测试 NMSE | 测试 RMSE |
|---|---|---|---|---|
| 按地图划分（主实验，论文口径） | 40,000 | 50 | 0.0770 | 0.0728 |
| **按样本对划分（诊断）** | **16,000** | **8** | **0.0172** | **0.0305** |

用**四分之一多一点**的训练量和**六分之一**的 epoch，测试误差降到了原来的 1/4.5，而且验证曲线到第 8 个 epoch 仍在单调下降（0.0451 → 0.0176），继续训练大概率还能再降一半。

### 6.2 这意味着什么

1. **实现没有坏。** 同一份代码、同一个损失、同一套超参，只把划分方式换掉，误差就从 0.077 掉到 0.017，说明模型、损失、图卷积、评估都是通的，不存在隐藏的实现错误。
2. **18 倍的差距可以被"划分方式"这一个变量完整解释。** 论文报告的 0.0043 在"测试地图参与过训练"的条件下是可达的；在论文自己声明的"按地图划分、测试地图完全未见"的条件下，我们只能做到 0.0770。
3. 换句话说：论文的零泛化差距不是靠某个更强的方法实现的，它更像是**任务设定本身让模型可以直接记忆地图**。在 500 张地图上，模型记住了"这片建筑群 + 这个发射机位置 → 这张增益图"，换一张没见过的地图就失效。

需要克制的地方：这个实验**不能证明**论文真的用了按样本对划分，只能证明该指标对划分方式极度敏感，且我们的 18 倍差距完全落在这一敏感区间内。要下定论需要作者提供划分脚本。

## 七、已排除的原因（共 11 项）

在拿到最终数字前，我们逐一排查了下列因素，均**不是**根因，详细过程见 `02-工程记录与问题排查.md`：

1. 建筑图与增益图错位——Tx 全部落在建筑外，强信号与建筑重叠率仅 0.1%
2. Tx 坐标约定错误——增益图 argmax 与天线图亮点逐样本一致
3. BatchNorm 统计量失配——train 模式下评估反而更差
4. 模型容量过大——缩到 14.96 M 无改善
5. AFM 门控方式（softmax vs sigmoid）——无差别
6. 数据增强（翻转）——无改善，且论文明确未使用
7. 观测点每 epoch 重抽样——固定观测也无改善
8. 训练长度不足——对照实验 5→26 epoch 曲线早已平台
9. 幅度校准偏差——线性校准后 NMSE 不变
10. 单编码器 vs 双编码器——两者都停在 0.21–0.28（验证集），排除结构问题
11. 验证集本身更难——确认 val 恰好是最暗的一档（target 均值 0.085 vs train 0.118 / test 0.141），这是 NMSE 分母变小导致的，不是模型问题

唯一有效果的改动是**观测点布设策略**：只在有信号的位置放传感器，验证集 NMSE 改善约 20%。论文未说明这一点，我们的主实验采用了它（属偏离，已在代码注释和本文档标注）。

## 八、如果要把差距补上，建议按这个顺序试

1. **先确认划分方式**：第六节已证明按样本对划分能把测试 NMSE 拉到 0.0172。在向作者确认划分脚本之前，所有改进都应以我们自己的 0.0770（按地图划分）为基线，不要拿 0.0043 当目标；
2. **换损失**：把 MSE 换成 L1 或 Charbonnier，或对高值区加权。当前误差形态（高值区被抹平）正是 MSE 的典型症状，这是最可能带来量级改善的单点改动；
3. **降容量 + 强正则**：24.55 M 参数对 40,000 样本偏大，试 8 M 级 + dropout / weight decay / 早停；
4. **数据侧**：56,080 个样本其实可以按"同一地图的不同 Tx"做交叉验证式增强，或引入对数域（dB）目标让动态范围更平缓；
5. **复核 AFM 与 GCN 的实现细节**：论文公式（eq. 8–9）对 patch 划分、KNN 的 k 值、MRConv 的邻接归一化描述不完整，仍有实现自由度。
