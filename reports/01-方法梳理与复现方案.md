# MFFGCN 论文复现：方法梳理与实现方案

> 论文：Han Zhang, Yu Han, Lingxin Meng, Guan Gui, Wei Xiang, Yun Lin,
> "MFFGCN: Multimodal Feature Fusion Graph Convolution Network for Radio Map
> Estimation With Uneven Spatial Sampling", **IEEE Transactions on Mobile
> Computing**, vol. 24, no. 12, pp. 13366–13379, Dec. 2025.
> DOI 对应页码 13366 起，PDF 共 17 页。

---

## 1. 论文要解决的问题

无线电地图（radio map）刻画发射机到任意位置的路径损耗，是频谱利用率分析和
网络覆盖评估的基础。实际部署中，物理阻隔、安全与隐私限制使部分区域无法部署
传感器，导致测量点**稀疏且空间分布不均匀**。

论文指出现有方法有两个短板：

1. 多数深度学习方法只做一次前向映射，没有显式利用观测点之间的空间相关性；
2. 观测点缺失的区域（observation-constrained region）缺乏与环境图的对应关系，
   直接回归容易产生不可靠输出。

MFFGCN 的思路是**两阶段**：先由双编码器 U-Net 得到粗估计，再把粗估计切成
区域 patch 建动态图，用图神经网络聚合 patch 间上下文补全细节，最后把残差
加回粗估计。

## 2. 方法结构

### 2.1 多模态特征融合网络（双编码器 U-Net）

输入两路模态：

| 模态 | 记号 | 维度 | 含义 |
|---|---|---|---|
| 稀疏观测 | $\mathbf{f}_i$ | $1\times256\times256$ | 测量点的路径损耗，其余为 0 |
| 环境信息 | $(\mathbf{m}_i,\mathbf{p}_i)$ | $2\times256\times256$ | 建筑分布图 + 发射机位置图 |

两个编码器分别提取特征 $F_o^s$（观测）与 $F_e^s$（环境），在每个 stage $s$
用 **AFM（自适应特征融合模块）** 融合：

$$\mathbf{F}'_e = \mathbf{W} \otimes \mathbf{F}_e, \qquad
\mathbf{W} = \mathrm{softmax}\big(\mathrm{conv}_{3\times3}(\mathbf{F}_e)\big)$$

$$\mathbf{F}^s = \mathrm{AFM}(\mathbf{F}_o^s, \mathbf{F}_e^s)
= \mathrm{conv}_{3\times3}\big(\mathbf{F}'_e \oplus \mathbf{F}_o^s\big)$$

其中 $\otimes$ 为逐元素乘，$\oplus$ 为通道拼接。softmax 保证权重落在 $(0,1)$ 且
通道和为 1，相当于让环境特征自己决定"哪些通道该被强调"，再与观测特征拼接卷积。

### 2.2 图卷积精修网络

1. **重构粗估计**：把观测点的真实测量值填回粗估计
   （$x_{in} = f_i \odot \text{mask} + \hat{y}_{coarse} \odot (1-\text{mask})$）；
2. **Patch 建图**：4 层 stride-2 卷积把 $256\times256$ 降到 $16\times16$，
   每个像素是一个 patch 节点，共 256 个节点，节点特征 256 维；
3. **动态图**：在特征空间用 KNN（$k=16$）连边，**每个样本、每次前向重新建图**，
   即论文强调的 dynamic graph，而非固定拓扑；
4. **图卷积**：3 层 **MRConv（max-relative graph convolution）**

   $$g(\cdot) = \Big[\mathbf{x}_i,\ \max_{j\in\mathcal{N}(i)}(\mathbf{x}_j-\mathbf{x}_i)\Big],
     \qquad h(\cdot) = g(\cdot)\mathbf{W}_{update}$$

   取邻居相对差的最大值而不是均值，避免过平滑，也让"最相似的邻居"起主导作用；
5. **Graph2Image**：4 层转置卷积（kernel 4、stride 2）回到 $256\times256$，
   再过一层 $3\times3$ 卷积输出 1 通道残差；
6. **残差合并**：$\hat{y} = \hat{y}_{coarse} + \hat{y}_{residual}$。

论文特别说明：图网络只学"粗估计与真值的差"，不重新估计整张图，这让训练更稳定。

### 2.3 损失函数

$$\mathcal{L} = \lambda_1 \mathcal{L}_{coarse} + \lambda_2 \mathcal{L}_{refine}
+ \lambda_3 \mathcal{L}_{MS\text{-}SSIM}$$

$\lambda_1=0.1,\ \lambda_2=1,\ \lambda_3=0.0001$。前两项是 MSE，第三项是
多尺度结构相似度损失。粗估计用 0.1 的小权重，主要是给图网络提供稳定的输入基底。

## 3. 数据与实验设置

### 3.1 数据集

**RadioMapSeer**（TU Berlin / Technion，CC BY 4.0）：701 张 $256\times256$
真实城市地图，来自安卡拉、柏林、格拉斯哥、卢布尔雅那、伦敦、特拉维夫 6 座城市，
每张地图 80 个发射机位置，WinProp 射线追踪仿真，1 m 分辨率。论文使用 **DPM**
（Dominant Path Model）传播模型。

预处理：路径损耗 $[-127,-47]$ dB 线性映射到 $[0,1]$，低于 $0.2$ 的像素置零，
剩余值再归一化回 $[0,1]$。

划分：500 张地图训练、100 验证、最后 100 测试（**按地图划分，非按样本**，
保证测试集的城市场景没有在训练中出现过）。

### 3.2 三种不均匀采样设置

| 设置 | 采样约束 | 观测点数 |
|---|---|---|
| Setup 1 | 全图均匀随机（对照组） | 10–300 |
| Setup 2 | 地图边缘贴边矩形区域占 25% 面积，该区域无观测 | 10–300 |
| Setup 3 | 受限区域面积在 10%–50% 随机变化 | 10–300 |

### 3.3 训练细节

Adam，初始学习率 $1\times10^{-3}$，共 50 epoch，第 40 epoch 学习率乘 0.1。
评价指标 NMSE 与 RMSE。

## 4. 复现决策（论文未写清或存在矛盾之处）

论文没有公开代码，以下细节按论文正文 + RadioUNet 官方实现推定，是本复现的
**主要不确定性来源**，解读结果时必须考虑。

### 4.1 U-Net 主干：Table I 与正文自相矛盾

- **Table I** 给出的通道数是 6 → 40 → 50 → 60 → 100 → 100 → 150 → 300 → 500，
  卷积核在 3/4/5/13 之间跳动，下采样位置也不规则（resolution 序列为
  256, 256, 128, 64, 64, 32, 32, 16, 8, 4，存在同尺寸连续两层）；
- **正文**却写 "The U-Net structure is shown in Table I, **which are similar to
  [32]**"，[32] 即 RadioUNet，其官方代码是标准五级 U-Net（32/64/128/256/512，
  kernel 3）。

两者不可能同时成立。核查 Table I 的 "Filter = 13" 与相邻层的 5 明显不协调，
更像是排版或录入错误。**本复现采用正文声明 + RadioUNet 官方实现的标准
U-Net（32/64/128/256/512，kernel 3）**，这也是文献中可核验的公共实现。
代价是参数量（24.55 M）不完全等于论文模型。

### 4.2 其他推定

| 项目 | 论文表述 | 本复现做法 |
|---|---|---|
| AFM 的 softmax 维度 | "weight matrix W with values between 0 and 1" | 通道维 softmax（每像素通道和为 1） |
| 观测点采样位置 | 未说明是否排除弱信号区 | 全图均匀随机，值取预处理后的 gain（可能为 0） |
| patch 建图的特征 | "semantic similarity" | 在拼接后的 patch 特征上算欧氏 KNN |
| 图卷积残差 | 未明确 | 每层 MRConv 外加恒等残差，缓解过平滑 |
| 受限区形状 | "append regions to one side" | 贴边矩形，面积占比按设定值 |
| 数据增强 | 未提 | 每个 epoch 重新随机抽观测点（这是必要的，否则相当于固定输入） |

### 4.3 未复现的部分

论文对比的 8 个基线（KNN、Kriging、AE、DeepAE、U-Net、RadioUNet、Pix2pix+、
RME-GAN）**未逐一重训**。本次复现聚焦 MFFGCN 本体，基线数据直接引用论文数值
作为参照。原因是 RME-GAN 与 Pix2pix+ 的复现需要各自的训练策略与超参，
工作量远超单篇方法复现的合理范围，且它们不是本文贡献。
