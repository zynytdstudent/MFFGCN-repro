> 论文：Zhang et al., *MFFGCN: Multimodal Feature Fusion Graph Convolution Network for Radio Map  
> Estimation With Uneven Spatial Sampling*, IEEE TMC, Vol. 24, No. 12, Dec. 2025  
> 全部数字来自修复 `dataset.py` 的 TX 坐标索引 bug 之后、用**同一份代码、固定评估随机种子**重跑的结果。

## 0. 一句话结论

**复现成立了**：Setup 1 上 MFFGCN 的 NMSE = **0.0041**，论文是 0.0043；U-Net 单编码器基线  
0.0059 对论文 0.0063。模型优劣顺序、每个 setup 的相对关系都对得上。

但消融给出一个和论文不一致的发现：**GCN 模块的贡献只有 2%，落在训练随机性（1.7%）范围内，  
统计上说不显著**；真正拉开差距的是**双编码器（+22%）**&#x548C;**残差细化（+18%）**。

## 2. 主结果：五个采样 Setup（完整 MFFGCN，50 epoch）

| Setup | 采样协议             | NMSE       | RMSE   | 粗估计 NMSE | 参数量     |
| ----- | ---------------- | ---------- | ------ | -------- | ------- |
| 1     | 全图均匀随机 10~300 点  | **0.0041** | 0.0167 | 0.0052   | 24.55 M |
| 2     | 25% 区域被遮蔽        | 0.0048     | 0.0181 | 0.0063   | 24.55 M |
| 3     | 遮蔽 10%~50% 随机    | 0.0051     | 0.0187 | 0.0072   | 24.55 M |
| 4     | 全像素、采样率 1%~10%   | 0.0017     | 0.0108 | 0.0023   | 24.55 M |
| 5     | 对半分区、1% 与 10% 密度 | 0.0019     | 0.0115 | 0.0028   | 24.55 M |

规律与论文一致：遮蔽比例越大误差越大（s1 < s2 < s3），观测密度越高误差越小（s4/s5 最好）。  
残差细化在每个 setup 上都把粗估计拉低了 21%~38%。

| 单编码器 U-Net（基线）         | 0.00500     | +22%      | 7.76 M  |

### 3.1 一个必须先说清的口径问题

这 32 个 `ab_*` / `FINAL_*` checkpoint 训练时都是 `obs_on_signal=True`（观测点只落在有信号的像素上），  
而论文口径是**按密度在全图撒点**（`False`）。两者差多少？`calib_mffgcn`（False，0.0046）  
对比 `FINAL_s1`（True，0.0041）—— **差 11%**，比 GCN 的 2% 大得多。

所以：**消融表内部横比是成立的**（所有行同口径），但和论文的绝对值不能直接对比；  
要出论文级的绝对数，得用 `obs_on_signal=False` 重训（8 个变体 × s1 ≈ 40 GPU-h）。

### 3.2 噪声基线（关键）

为了判断"2% 算不算真的差"，做了两组噪声测量：

| 噪声来源 | 做法                                 | 幅度            |
| ---- | ---------------------------------- | ------------- |
| 评估噪声 | 同一权重换 3 个 eval seed（111/222/333）   | **0.5%~0.7%** |
| 训练噪声 | 同配置两次独立训练（`bs15_s1` vs `FINAL_s1`） | **1.7%**      |

结论：**评估本身很稳（<1%），但两次训练的差异就有 1.7%**。所以 2.0%（去 GCN）和 1.2%  
（静态图）都落在噪声里，不能据此说 GCN 有用；而 18%（去残差）、22%（单编码器）、25%（concat）  
远超噪声，是可靠结论。

## 4. 与论文对照

### 4.1 主表（Setup 1）

| 方法     | 论文 NMSE | 本次 NMSE    | 论文 RMSE | 本次 RMSE |
| ------ | ------- | ---------- | ------- | ------- |
| U-Net  | 0.0063  | **0.0059** | 0.0182  | 0.0201  |
| MFFGCN | 0.0043  | **0.0041** | 0.0150  | 0.0167  |

NMSE 对得很准（我们甚至略好），RMSE 系统性地高 11%~14%。这不是错，是归一化口径差异：  
由 `RMSE / sqrt(NMSE)` 反推目标图的 RMS，论文是 0.229，我们是 0.261 —— 我们的目标图能量高 14%，  
而 NMSE 的分母平方能量会把这个常数约掉。**所以横向比较看 NMSE，RMSE 只能自己跟自己比。**

### 4.2 消融（论文 Table V 的说法 vs 本次）

| 论文结论                          | 本次结果                | 判断             |
| ----------------------------- | ------------------- | -------------- |
| 去掉 GCN 明显变差                   | +2.0%（噪声内）          | **未复现**        |
| 动态图优于静态图                      | +1.2%（噪声内）          | **未复现**        |
| 去掉残差后 NMSE 0.0043→0.0231（4 倍） | 0.0041→0.0048（+18%） | **方向一致、幅度差很多** |
| 单编码器明显更差                      | +22%                | 复现             |
| AFM 优于 concat / add / 两种注意力   | 完整模型最好，concat 最差    | 复现             |
| additive 融合效果差                | +15%，居中             | 基本复现           |

**为什么不一致（我的解释，可写进汇报）**：

1. **GCN 的收益可以被容量补偿。** 完整模型里 GCN 把 coarse 0.0052 拉到 fine 0.0041（-21%），  
   模块是**真的在工作**；但把 GCN 整个删掉后，双编码器 U-Net 端到端也能自己学出同样的映射  
   （24.15M 参数只比完整模型少 0.4M）。也就是说 GCN 提供的是"分工"，不是"额外的表达能力"。
2. **论文的 w/o Residual 数字像是欠训练的产物。** 论文报 0.0231，我们 ep1 的 w/o-residual 是  
   0.0223、第 50 epoch 是 0.0048 —— 0.0231 这个量级恰好对应"只训了几个 epoch"。作者可能用了  
   和我们一样的早停选点方式，被某个异常 val 值骗了（和我们踩的坑同源）。
3. **动态图 vs 静态图**：城市布局是静态的，patch 级 KNN 图在两种模式下差异本来就小，  
   参数量完全一样（24.55M），看不出差别符合直觉。
