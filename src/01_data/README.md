# 01_data — 数据层

**职责**：把原始 PNG 变成网络能吃的张量。这一层决定了"模型看到什么"，
也是复现里最容易出错的地方。

## 文件

| 文件 | 作用 | 什么时候跑 |
|---|---|---|
| `prepare_data.py` | 56080 张 PNG → 5 个 npy 缓存文件 | 只跑一次 |
| `dataset.py` | `Dataset` 类 + 5 种采样设定 + 在线抽观测点 | 每次训练都调用 |

## 一条样本的 6 个张量

```
obs     (1,256,256)  稀疏观测值，未采样处为 0
env     (2,256,256)  通道0=建筑物, 通道1=发射机
mask    (1,256,256)  1=该像素被采样
target  (1,256,256)  完整真值，值域 [0,1]
allowed (1,256,256)  1=允许布传感器（s2/s3 会挖掉一块）
index   ()           全局行号
```

恒等式：`obs == target * mask`

## 五个 Setup

| Setup | 采样方式 | 观测点数 |
|---|---|---:|
| s1 | 全图均匀随机 | 10 ~ 300 |
| s2 | 挖掉贴边的 25% 矩形区域 | 10 ~ 300（在剩余区域） |
| s3 | 挖掉贴边 10%~50% 随机面积 | 10 ~ 300 |
| s4 | 全图按 1%~10% **密度**采样 | 655 ~ 6554 |
| s5 | 切两半，分别 1% / 10% 密度 | ~3600 |

⚠ s2/s3 控制"**面积**"，s4/s5 控制"**密度**"，语义不同，代码里用
`regions is None` 分成两条路径。

## 数据划分（不要改）

```
train  city[0:500]     40000 样本
val    city[500:600]    8000 样本
test   city[600:701]    8080 样本
```

按**城市**切，不是按样本切。`--split-mode pair` 是诊断模式，会造成信息泄漏。

## 已知坑

- `tx_coords.npy` 必须用**全局行号 idx** 索引，用局部下标会让 val/test 的
  发射机位置全部错乱（NMSE 卡在 0.09）。见 `dataset.py` 里的 ⚠ 注释。
- `build_loaders` 里 val/test 的 `obs_on_signal` 必须和训练一致。
